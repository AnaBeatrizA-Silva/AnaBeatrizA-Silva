I'm a Junior Software Developer with professional experience in developing and maintaining ERP systems, primarily working with Vue3 and TypeScript.

My experience also includes working with relational databases, SQL, data modeling, and PostgreSQL database migrations in a professional environment.

I'm currently pursuing a Bachelor's degree in Software Engineering and exploring opportunities to grow in the data field, particularly in data analysis, databases, and data engineering.
